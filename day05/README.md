# Day 05: Lab Data Analysis (FASTA Parser)

This project provides a utility tool to read biological sequence files (FASTA format) and analyze their structural properties, specifically the GC content percentage.

## Features
- Parses standard FASTA files, skipping metadata header lines.
- Calculates total sequence length.
- Computes **GC Content Percentage**, which is crucial for determining DNA structural stability.

## Files
- `dna_analyzer.py`: Main execution script.
- `test_analyzer.py`: Unit tests to verify computation correctness.
- `sample.fasta`: Example input file containing a mock DNA sequence.
